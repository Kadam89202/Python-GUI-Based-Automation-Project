# 🐍 Python GUI-Based Data Cleaning Automation Tool

## Project Overview

The Python GUI-Based Data Cleaning Automation Tool is a desktop application developed using Python and Tkinter to simplify Excel data cleaning tasks. The application enables users to clean datasets through an intuitive graphical interface without writing any code. It automates common preprocessing operations such as removing duplicate records, deleting blank rows, trimming extra spaces, and converting text to title case.

## Project Objective

The objective of this project is to automate repetitive Excel data cleaning tasks, reduce manual effort, improve data quality, and increase productivity through a simple and user-friendly desktop application.

## Features

- 📂 Browse and select Excel files (.xlsx, .xls)
- 📁 Choose an output folder for cleaned files
- 🗑️ Remove duplicate rows
- 📄 Remove blank rows
- ✂️ Trim leading and trailing spaces from text columns
- 🔤 Convert text values to Title Case
- 💾 Automatically save the cleaned Excel file
- 🔄 Reset file paths and cleaning options
- 🖥️ Easy-to-use graphical user interface (GUI)

## Technologies Used

- Python
- Tkinter
- Pandas
- OpenPyXL
- OS Module

## Workflow

1. Select an Excel file.
2. Choose the output folder.
3. Select the required data cleaning options.
4. Click **Clean Data**.
5. The cleaned Excel file is automatically generated and saved in the selected location.
